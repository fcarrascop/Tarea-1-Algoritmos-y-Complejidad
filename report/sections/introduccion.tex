En este informe analizaremos experimentalmente algoritmos para dos problemas clásicos de la computación: ordenamiento de arreglos unidimensionales y multiplicación de matrices cuadradas.

Para ambos problemas con algoritmos ampliamente conocidos y usados, el objetivo de este reporte es medir su comportamiento real y relacionarlo con su comportamiento teórico, mediante el análisis de tiempo de ejecución y uso de memoria con entradas controladas sobre 6 algoritmos distintos (4 para ordenamiento de arreglos y 2 para multiplicación de matrices). Con la final de encontrar factores que la notación asintótica no captura.
